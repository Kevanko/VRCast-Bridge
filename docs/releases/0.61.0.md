## What's new / Что нового

**Linux.** VRCast Bridge runs on Linux (X11): screen, window and region capture, PulseAudio/PipeWire sound, a window with a tray icon. Start with `./bin/vrcast`.
**Linux.** Программа работает в Linux (X11): захват экрана, окна и области, звук PulseAudio/PipeWire, окно со значком в трее. Запуск: `./bin/vrcast`.

**Phone remote.** Settings → Phone: scan the QR code with your phone, or open the address and enter the code. The phone is remembered; only paired devices can control the PC.
**Пульт с телефона.** «Настройки → Телефон»: наведите камеру на QR-код или откройте адрес и введите код. Телефон запоминается; управлять ПК могут только привязанные устройства.

**New look.** Settings show one section at a time. New themes: Midnight (default), Minimal dark and light, Stage, Terminal, Matrix. The player bar is cleaner and easier to read.
**Новый вид.** Настройки открываются по разделам. Новые темы: «Полночь» (по умолчанию), «Минимализм» тёмная и светлая, «Сцена», «Терминал», «Матрица». Нижняя панель плеера читается лучше.

**Faster public links.** A free link appears as soon as it actually serves video; speed is measured afterwards.
**Быстрые ссылки быстрее.** Бесплатная ссылка появляется, как только реально отдаёт видео; скорость меряется после.

**Network cards.** Only cards with internet access are offered, and the choice survives an address change.
**Сетевые карты.** В выборе только карты с выходом в интернет; выбор не слетает при смене адреса.

**Your own server in one command:** `curl -fsSL https://raw.githubusercontent.com/Kevanko/VRCast-Bridge/main/server/install.sh | sudo bash`
**Свой сервер одной командой:** `curl -fsSL https://raw.githubusercontent.com/Kevanko/VRCast-Bridge/main/server/install.sh | sudo bash`

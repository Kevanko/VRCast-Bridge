## What's new / Что нового

**Graphics card freezes.** If the graphics card encoder stops giving frames again and again, the app switches to the processor until the end of the broadcast instead of restarting the track in a loop. The next broadcast tries the graphics card again.
**Зависания видеокарты.** Если кодировщик видеокарты раз за разом перестаёт выдавать кадры, программа до конца эфира переходит на процессор, а не перезапускает трек по кругу. Следующий эфир снова пробует видеокарту.

**No false restart at start.** The broadcast no longer jumps back to the start of the track a second after it begins.
**Без ложного перезапуска на старте.** Эфир больше не перематывает трек в начало через секунду после старта.

**Quick link before the broadcast.** Until the broadcast starts, a working link shows as ready instead of «not serving the stream».
**Быстрая ссылка до эфира.** Пока эфир не начат, рабочая ссылка показывается готовой, а не «не отдаёт поток».

**Cleaner log, more details for help.** Repeated errors no longer flood the log. Each start writes system details to the log — Windows version, processor, memory, graphics card and its driver, FFmpeg, VPN — so problems are easier to find. No passwords, keys or server addresses.
**Журнал чище, а для помощи — подробнее.** Повторяющиеся ошибки больше не заливают журнал. При каждом запуске в журнал пишутся сведения о системе — версия Windows, процессор, память, видеокарта и её драйвер, FFmpeg, VPN, — чтобы проблему было проще найти. Без паролей, ключей и адресов серверов.

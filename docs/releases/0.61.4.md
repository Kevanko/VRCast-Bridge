## What's new / Что нового

**Graphics card freezes.** If the graphics card encoder stops giving frames again and again, the app switches to the processor until the end of the broadcast instead of restarting the track in a loop. The next broadcast tries the graphics card again.
**Зависания видеокарты.** Если кодировщик видеокарты раз за разом перестаёт выдавать кадры, программа до конца эфира переходит на процессор, а не перезапускает трек по кругу. Следующий эфир снова пробует видеокарту.

**No false restart at start.** The broadcast no longer jumps back to the start of the track a second after it begins.
**Без ложного перезапуска на старте.** Эфир больше не перематывает трек в начало через секунду после старта.

**Quick link before the broadcast.** Until the broadcast starts, a working link shows as ready instead of «not serving the stream».
**Быстрая ссылка до эфира.** Пока эфир не начат, рабочая ссылка показывается готовой, а не «не отдаёт поток».

**Cleaner log, more details for help.** Repeated errors no longer flood the log. The detailed log now records system details at each start (Windows version, processor, memory, graphics card and its driver, FFmpeg, VPN), how every broadcast process was started and how it ended, all FFmpeg errors, a broadcast health snapshot every 30 seconds and settings changes. No passwords or keys.
**Журнал чище, а для помощи — подробнее.** Повторяющиеся ошибки больше не заливают журнал. Подробный журнал теперь хранит сведения о системе при каждом запуске (версия Windows, процессор, память, видеокарта и её драйвер, FFmpeg, VPN), как запущен и чем кончился каждый процесс эфира, все ошибки FFmpeg, снимок состояния эфира раз в 30 секунд и изменения настроек. Без паролей и ключей.

**Report for help.** Log → «Report for help» saves one file with everything needed to find a problem and shows it in Explorer — just send it.
**Отчёт для помощи.** Журнал → «Отчёт для помощи» сохраняет один файл со всем, что нужно для поиска проблемы, и показывает его в проводнике — остаётся отправить.

# Проверка в чистой Windows

Набор гоняет программу в Windows Sandbox — одноразовой чистой системе без
.NET, Node и ffmpeg. Так проверяется путь нового пользователя: установка,
догрузка зависимостей, эфир, захват экрана, публичная ссылка.

## Как запустить

1. Один раз включите песочницу (нужны права администратора):
   `Enable-WindowsOptionalFeature -Online -FeatureName Containers-DisposableClientVM -All`
   и перезагрузитесь.
2. Соберите программу и положите рядом с этими файлами:
   - `VRCast Bridge.exe` — свежая сборка;
   - `clip.mp4` — любой короткий ролик для проверки воспроизведения.
3. Скопируйте папку в путь без кириллицы, например `C:\Users\<вы>\vrcast-sandbox`,
   поправьте в `vrcast-test.wsb` строку `HostFolder` и запустите этот файл.

Отчёт появится там же: `sandbox-report.txt`, рядом лягут журналы программы.

## Что учтено

- PowerShell в песочнице не работает (жалуется на отсутствующий .NET), поэтому
  прогон написан на cmd и на Node, который программа скачивает себе сама.
- Файлы из общей папки не запускаются напрямую — скрипт сначала копирует себя
  и установщик внутрь песочницы.
- Команда входа срабатывает раньше, чем подключается общая папка: перед стартом
  стоит пауза.
